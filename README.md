# DG Caddy

Find disc golf courses near you, check in, and chat with other players at a course.

Built with Vite, React, TypeScript, Tailwind/shadcn-ui, and Supabase.

## Development

```sh
npm install
cp .env.example .env   # fill in values
npm run dev
```

## Data

Course data (`courses.csv`, ~7,000 courses with name, location, hole count) is not included in this repository.
